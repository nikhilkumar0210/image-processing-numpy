# Image Processing with NumPy

Converts an RGB image to grayscale and applies binary thresholding using pure NumPy array operations.

## What it does
- Splits image into R, G, B channels using array slicing
- Converts to grayscale using the standard luminosity formula
- Applies thresholding to create a binary (black/white) image
- Visualizes all three stages side by side

## Tools
NumPy, Matplotlib
